# Jaumo Growth Audit

**Live → https://eddieatadapty.github.io/jaumo-flow-rebuild/**

Five ideas to turn more Jaumo users into subscribers, each built into a clickable version of Jaumo's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the answers you collect | +10–20% CR to purchase |
| 02 | Let them like someone before you ask | +5–15% CR to purchase |
| 03 | Lead with the proof you already have | +10–15% CR to purchase |
| 04 | Make the 3-month saving impossible to miss | +10–15% ARPU, more 3-month plans |
| 05 | Catch the people who close the paywall | +10–15% ARPU |

Every price, rating and feature comes from Jaumo's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Jaumo. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
